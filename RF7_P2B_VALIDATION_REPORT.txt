Architecture invariants
- Legacy device auth remains the only socket authority: PASS
- SH-AUTH-V1 handled only after legacy authentication: PASS
- Shadow PASS does not grant authority: PASS
- Shadow FAIL does not disconnect device / mark offline: PASS
- Shadow messages use a separate per-device generation lane from ACK/state traffic: PASS
- Challenge bound to canonical UUID + legacy Device DB id + keyVersion + socket generation: PASS
- 30-second challenge lifetime: PASS
- One proof attempt consumes challenge: PASS
- Replayed consumed challenge distinguished/rejected: PASS
- Socket close destroys its outstanding challenge: PASS
- HMAC comparison uses crypto.timingSafeEqual: PASS
- Credential is AES-256-GCM wrapped before DB storage: PASS
- Admin status endpoint never selects ciphertext/IV/tag: PASS
- Raw authKey is never returned or logged: PASS
- Existing commandService.ts unchanged: PASS
- Existing security.ts unchanged: PASS
- Existing db.ts unchanged: PASS
- Existing server.ts unchanged: PASS

Important limitation
- A full `npm run build` with Prisma-generated types was not executed in this sandbox because npm dependency installation was unavailable/timed out. The actual Render build remains the authoritative TypeScript+Prisma integration compile gate. Deploy first with SHADOW_AUTH_ENABLED=false; if Render build reports any compiler/Prisma error, do not enable P2B and use that exact build log for correction.
