Copy every item inside that folder to the existing repository root, including
.github, .gitignore, .node-version and .env.example.
Do not upload the ZIP itself or nest the entire folder inside the repository.

Repository: https://github.com/smarthandicraftsdata-rgb/sh-lamp-cloud-render

the default branch. Use Actions > Render keep-alive to confirm its first run.

with Add file > Create new file using their complete supplied paths.
